# Netflix Clone

A responsive Netflix landing page clone built using HTML and CSS.

## Features

- Responsive design for desktop, tablet, and mobile
- Netflix-style hero section
- Trending movies section
- Reasons to join section
- FAQ section
- Footer section
- Custom font
- CSS hover effects

## Technologies Used

- HTML5
- CSS3

## Project Structure

- `index.html` - Main HTML file
- `header.css` - Header styles
- `hero-section.css` - Hero section styles
- `trending-section.css` - Trending section styles
- `faq-section.css` - FAQ styles
- `footer.css` - Footer styles
- `images/` - Images and SVG assets
- `fonts/` - Font files

## Purpose

This project was created to practice HTML, CSS, responsive design, layouts, and recreating a real-world website interface.
